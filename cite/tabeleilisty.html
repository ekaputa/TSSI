Eryk Kaputa 1P

Tabele HTML

Najważniejsze znaczniki

tabela -

Tabele służą do przedstawiania danych w wierszach i kolumnach.



<table> -

Znacznik rozpoczynający tabelę.



<tr> -

Tworzy nowy wiersz tabeli.



<td> -

Tworzy zwykłą komórkę tabeli.



<th> -

Tworzy komórkę nagłówkową tabeli.



<caption> -

Dodaje podpis tabeli.

Atrybuty tabel

Najważniejsze atrybuty

border -

Dodaje obramowanie tabeli.



colspan -

Łączy kilka kolumn w jedną komórkę.



rowspan -

Łączy kilka wierszy w jedną komórkę.



cellpadding -

Ustawia odstęp między tekstem a obramowaniem komórki.



cellspacing -

Ustawia odstęp między komórkami tabeli.

Listy HTML

Rodzaje list

<ul> -

Lista nieuporządkowana oznaczana punktami.



<ol> -

Lista uporządkowana numerowana.



<li> -

Pojedynczy element listy.



type -

Zmienia rodzaj numeracji listy.



start -

Określa numer od którego ma zacząć się lista.

Zagnieżdżanie list

Podlisty

zagnieżdżanie list -

Można umieszczać listy wewnątrz innych list tworząc podpunkty.



listy wielopoziomowe -

Pozwalają tworzyć bardziej rozbudowane menu i struktury informacji.



menu nawigacyjne -

Listy bardzo często używane są do tworzenia menu stron internetowych.



zagnieżdżanie tabel -

Zagnieżdżanie tabel polega na umieszczaniu jednej tabeli wewnątrz komórki innej tabeli. Dzięki temu można tworzyć bardziej rozbudowane układy danych oraz bardziej szczegółowe struktury informacji.



tabela w tabeli -

Aby umieścić tabelę w tabeli należy wstawić nową tabelę wewnątrz znacznika <td>.



zastosowanie zagnieżdżania tabel -

Zagnieżdżone tabele używane są do tworzenia bardziej skomplikowanych układów danych oraz dawniej były wykorzystywane do budowania układu strony internetowej.



wady zagnieżdżania tabel -

Zbyt duża liczba zagnieżdżonych tabel może utrudniać czytanie kodu html oraz spowalniać działanie strony internetowej.



przykład zagnieżdżania tabel -

  • <table>
  • <tr>
  • <td>
  • <table>
  • <tr><td>tekst</td></tr>
  • </table>
  • </td>
  • </tr>
  • </table>
