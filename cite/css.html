Podstawy

Najważniejsze informacje o CSS

CSS -

CSS czyli Cascading Style Sheets to kaskadowe arkusze stylów. Służą do zmieniania wyglądu strony internetowej. Dzięki css można zmieniać kolory, czcionki, odstępy, animacje, położenie elementów i wiele innych rzeczy związanych z wyglądem strony. Html odpowiada za strukturę strony, natomiast css odpowiada za jej wygląd.



kaskadowość -

Kaskadowość oznacza, że style są stosowane w określonej kolejności. Style zapisane później mają wyższy priorytet niż te zapisane wcześniej.



arkusz stylów -

Plik zawierający style css. Najczęściej zapisuje się go z rozszerzeniem .css i podłącza do strony html.



składnia css -

Każdy styl css składa się z selektora oraz deklaracji zapisanych w nawiasach klamrowych.

Przykład:

p { color: red; font-size: 20px; }

W tym przykładzie selektorem jest p, właściwościami są color oraz font-size, a wartościami red i 20px.



komentarze css -

Komentarze służą do opisywania kodu css. Nie są widoczne na stronie internetowej.

Przykład:

/* komentarz */

Rodzaje

Różne opcje użycia CSS

inline css -

Styl zapisany bezpośrednio w znaczniku html za pomocą atrybutu style.

Przykład:

<p style="color:red;">Tekst</p>



internal css -

Styl zapisany w znaczniku <style> w sekcji head dokumentu html.



external css -

Styl zapisany w osobnym pliku .css. Jest to najlepszy sposób dodawania css do strony.



<link> -

Znacznik służący do podłączania pliku css do dokumentu html.

Przykład:

<link rel="stylesheet" href="style.css">

Selektory

Wybieranie znaczników

selektor znacznika -

Pozwala stylować wszystkie znaczniki danego typu np. wszystkie paragrafy lub nagłówki.



selektor klasy -

Pozwala przypisać styl do wielu elementów. Klasy zapisujemy za pomocą kropki.

Przykład:

.menu { background-color: blue; }



selektor id -

Pozwala ostylować jeden konkretny element. Id zapisujemy za pomocą znaku #.



selektor uniwersalny -

Zapisywany za pomocą gwiazdki *. Styluje wszystkie elementy na stronie.



selektor grupowy -

Pozwala stylować kilka elementów jednocześnie.

Przykład:

h1, h2, p { color:black; }

Właściwości

Najważniejsze właściwości

color -

Zmienia kolor tekstu.



background-color -

Zmienia kolor tła elementu.



font-size -

Ustawia rozmiar tekstu.



font-family -

Zmienia rodzaj czcionki.



width i height -

Ustawiają szerokość i wysokość elementu.



margin -

Ustawia odstęp na zewnątrz elementu.



padding -

Ustawia odstęp wewnątrz elementu.



border -

Dodaje obramowanie elementu.



display -

Określa sposób wyświetlania elementu.



position -

Określa sposób pozycjonowania elementu.

Dziedziczenie

Dziedziczenie właściwości

dziedziczenie CSS -

Mechanizm, dzięki któremu elementy potomne przejmują niektóre style od elementów nadrzędnych, np. kolor tekstu lub czcionkę.



element nadrzędny -

Element zawierający inne elementy wewnątrz siebie.



element potomny -

Element znajdujący się wewnątrz innego elementu.



inherit -

Wartość CSS wymuszająca dziedziczenie właściwości od elementu nadrzędnego.



dziedziczone właściwości -

Najczęściej dziedziczone są kolor tekstu, czcionka oraz wysokość linii.



brak dziedziczenia -

Niektóre właściwości, np. dotyczące położenia na stronie, marginesów, koloru tła lub obramowania, nie są dziedziczone automatycznie.



wagi -

Wagi określają priorytet stosowania stylów. Wartości od 0 do 1000 są przypisywane do różnych typów selektorów. Dla selektora znacznika wynosi 1, dla klasy 100, dla id 1000 a dla stylu lokalnego 10000.
