Animacje

Najważniejsze pojęcia

animacja -

Efekt wizualny zmieniający wygląd lub położenie elementu na stronie.



@keyframes -

Instrukcja definiująca kolejne etapy animacji.



animation-name -

Określa nazwę animacji przypisanej do elementu.



animation-duration -

Ustawia czas trwania animacji.



animation-iteration-count -

Określa liczbę powtórzeń animacji.



animation-delay -

Ustawia opóźnienie przed rozpoczęciem animacji.



animation-timing-function -

Określa szybkość przebiegu animacji.

Transformacje

Najważniejsze właściwości

transform -

Właściwość umożliwiająca zmianę wyglądu lub położenia elementu.



translate -

Przesuwa element w poziomie lub pionie.



rotate -

Obraca element o określoną liczbę stopni.



scale -

Powiększa lub zmniejsza element.



skew -

Pochyla element pod określonym kątem.



transition -

Tworzy płynne przejście pomiędzy zmianami stylów.

Klasy

Najważniejsze informacje

class -

Atrybut HTML pozwalający przypisywać style do elementów.



.nazwa-klasy -

Sposób zapisu klasy w CSS.



:hover -

Pseudoklasa aktywująca styl po najechaniu kursorem.



:active -

Pseudoklasa aktywująca styl podczas kliknięcia.



:focus -

Pseudoklasa aktywująca styl po zaznaczeniu elementu.



łączenie klas -

Jeden element może posiadać kilka klas jednocześnie.

Przykłady

Najczęstsze zastosowania

efekt hover -

Zmiana koloru lub rozmiaru elementu po najechaniu myszką.



obracanie elementu -

Animacja wykorzystująca rotate do obracania obiektu.



powiększanie przycisku -

Efekt scale zwiększający rozmiar przycisku.



przesuwanie elementu -

Animacja translate przesuwająca obiekt po stronie.



zanikanie -

Efekt zmiany przezroczystości elementu.



animowane menu -

Płynne rozwijanie lub wysuwanie menu na stronie.

SVG

Najważniejsze informacje

SVG -

SVG (Scalable Vector Graphics) to format grafiki wektorowej używany w HTML do tworzenia ikon, rysunków i prostych ilustracji, które nie tracą jakości przy powiększaniu.



<svg> -

Znacznik HTML służący do tworzenia grafiki wektorowej bezpośrednio w kodzie strony.



viewBox -

Atrybut określający obszar widoczny w SVG i jego proporcje.



path -

Element SVG pozwalający rysować dowolne kształty za pomocą współrzędnych.



fill -

Atrybut określający kolor wypełnienia kształtu SVG.



stroke -

Atrybut określający kolor obramowania w SVG.
