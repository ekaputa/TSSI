Układ strony

Najważniejsze pojęcia

układ strony (layout) -

Układ strony określa rozmieszczenie elementów na stronie internetowej.



<header> -

Górna część strony zawierająca np. logo lub menu.



<main> -

Główna część strony z najważniejszą treścią.



<nav> -

Element przechowujący menu nawigacyjne.



<footer> -

Dolna część strony zawierająca np. kontakt lub prawa autorskie.



div -

Uniwersalny kontener używany do budowania układu strony.

Wymiary

Najważniejsze właściwości

width -

Określa szerokość elementu.



height -

Określa wysokość elementu.



max-width -

Ustawia maksymalną szerokość elementu.



min-width -

Ustawia minimalną szerokość elementu.



max-height -

Ustawia maksymalną wysokość elementu.



min-height -

Ustawia minimalną wysokość elementu.

Marginesy

Najważniejsze właściwości

margin -

Tworzy odstęp na zewnątrz elementu.



padding -

Tworzy odstęp wewnątrz elementu.



margin-top -

Ustawia margines górny elementu.



margin-bottom -

Ustawia margines dolny elementu.



padding-left -

Ustawia wewnętrzny odstęp po lewej stronie.



padding-right -

Ustawia wewnętrzny odstęp po prawej stronie.

Position

Rodzaje pozycjonowania

position -

Właściwość określająca sposób pozycjonowania elementu.



static -

Domyślne pozycjonowanie elementu.



relative -

Umożliwia przesuwanie elementu względem jego normalnej pozycji.



absolute -

Pozycjonuje element względem najbliższego elementu nadrzędnego.



fixed -

Przykleja element do określonego miejsca na ekranie.



sticky -

Element zachowuje się jak relative, a po przewinięciu jak fixed.



z-index -

Określa kolejność nakładania się elementów.

Flexbox

Najważniejsze informacje

display: flex -

Ustawia element jako kontener flexbox.



flex-direction -

Określa kierunek układania elementów.



row -

Układa elementy poziomo.



column -

Układa elementy pionowo.



justify-content -

Wyrównuje elementy w poziomie.



align-items -

Wyrównuje elementy w pionie.



gap -

Ustawia odstępy pomiędzy elementami flexbox.



flex-wrap -

Pozwala elementom przechodzić do kolejnego wiersza.
