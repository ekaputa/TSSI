Formularze HTML

Najważniejsze pojęcia

formularz -

Formularze służą do przesyłania danych od użytkownika do serwera. Umożliwiają logowanie, rejestrację oraz wpisywanie różnych informacji.



<form> -

Znacznik rozpoczynający formularz.



action -

Atrybut określający gdzie mają zostać wysłane dane formularza.



method -

Określa sposób wysyłania danych. Najczęściej używa się metod GET oraz POST.



GET -

Metoda przesyłająca dane w adresie url.



POST -

Metoda przesyłająca dane w sposób niewidoczny dla użytkownika.

Znacznik input

Najważniejsze informacje

<input> -

Najważniejszy znacznik formularzy. Służy do tworzenia pól do wpisywania danych.



type -

Atrybut określający typ pola input.



name -

Określa nazwę pola formularza wysyłaną do serwera.



value -

Ustawia wartość pola input.



placeholder -

Wyświetla podpowiedź wewnątrz pola formularza.



required -

Wymaga wypełnienia pola przed wysłaniem formularza.



disabled -

Blokuje możliwość używania pola formularza.

Typy input

Najpopularniejsze typy pól

text -

Zwykłe pole tekstowe.



password -

Pole do wpisywania hasła. Znaki są ukrywane.



email -

Pole wymagające wpisania poprawnego adresu email.



number -

Pole umożliwiające wpisywanie liczb.



checkbox -

Pole wyboru umożliwiające zaznaczenie kilku opcji.



radio -

Pole wyboru umożliwiające zaznaczenie tylko jednej opcji.



submit -

Przycisk wysyłający formularz.



reset -

Przycisk resetujący dane formularza.



file -

Pole umożliwiające przesyłanie plików.

Inne znaczniki formularzy

Dodatkowe elementy

<label> -

Etykieta opisująca pole formularza.



<textarea> -

Pole umożliwiające wpisywanie większej ilości tekstu.



<select> -

Tworzy listę rozwijaną.



<option> -

Pojedyncza opcja listy rozwijanej.



<button> -

Tworzy przycisk formularza.



fieldset -

Grupuje elementy formularza.



legend -

Dodaje tytuł dla grupy elementów formularza.
